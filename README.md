#  Lumina - Dark & Light Mode Toggle Dashboard

A modern, responsive dashboard application featuring a seamless dark and light mode toggle switch built with Vanilla JavaScript, CSS variables, and LocalStorage persistence.

##  Features
- **Dynamic Theme Switching**: Smoothly toggle between Light and Dark modes with custom sun and moon icon indicators.
- **CSS Custom Properties**: Uses CSS root variables to dynamically update background colors, card panels, text tones, and borders instantly.
- **LocalStorage Persistence**: Automatically saves your theme preference in browser storage so your selection stays active across page reloads.
- **Modern Dashboard UI**: Includes welcome banners, statistics cards with trend badges, and a live system activity table.
- **Fully Responsive**: Adapts fluidly to mobile, tablet, and desktop viewports.

##  Getting Started
1. Clone the repository.
2. Open `index.html` in your browser or launch it using VS Code Live Server.
